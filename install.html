Bubble Level

Inclinometer and spirit level for the Rabbit R1 with three modes: line, vials and 3D. Version 0.1.1.

Install

  1. Open the creations card on the R1.
  2. Choose “add via QR code” and scan this code.
  3. Updating: uninstall the old card first, then scan the new code (the R1 remembers the address).

Open it in a browser: index-v0.1.1.html (mouse = tilt).

Controls

Side buttonSwitch mode: line → vials → 3D
Long pressCalibrate (“Calibrated”)
Double clickReset calibration (“Reset”)
Scroll wheelUnit: degrees, % slope, mm/m
Tap the big numberHOLD (freeze the value), tap again to release
Tap a vialLock that vial, tap again = automatic

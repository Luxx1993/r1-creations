Todoist für den R1

Mit dem R1 scannen: Creations-Karte → „add via QR code“.

  1. Alte Todoist-Karte auf dem R1 zuerst deinstallieren (der R1 cached die Install-URL).
  2. QR scannen, Karte öffnen.
  3. Im Setup den API-Token eintippen (Todoist → Einstellungen → Integrationen → Entwickler), „Testen“, dann „Speichern“.
  4. Ohne Token: „Demo ansehen“. Setup später: Bildschirm ca. 1 s halten.

Der Token steht nie im QR-Code und nie in einer URL.

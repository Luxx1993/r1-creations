Wasserwaage

Neigungs- und Wasserwaagen-App für den Rabbit R1 mit drei Modi: Linie, Libellen und 3D. Version 0.1.1.

Installieren

  1. Auf dem R1 die Creations-Karte öffnen.
  2. „add via QR code“ wählen und diesen Code scannen.
  3. Update: alte Karte zuerst deinstallieren, dann den neuen Code scannen (der R1 merkt sich die Adresse).

Direkt im Browser öffnen: index-v0.1.1.html (Maus = Neigung).

Bedienung

SeitentasteModus wechseln: Linie → Libellen → 3D
Langer DruckKalibrieren („Kalibriert“)
DoppelklickKalibrierung zurücksetzen („Zurückgesetzt“)
ScrollradEinheit: Grad, % Gefälle, mm/m
Große Zahl antippenHOLD (Wert einfrieren), nochmal tippen gibt frei
Libelle antippenLibelle fest wählen, nochmal tippen = automatisch
